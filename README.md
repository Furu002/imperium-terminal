# IMPERIUM

<img src="build/icon-preview.png" width="96" alt="IMPERIUM terminal icon">

라틴어로 통솔권·지휘권을 뜻하는 **IMPERIUM**은 역할과 스킬을 갖춘 AI 에이전트에게 업무를 맡기는 로컬 운영 터미널입니다. 첫 화면의 조직도에서 책임·연결 모델·담당 업무·스킬과 전달 대상을 확인합니다. 이름과 직함은 자유롭게 정하고, 도구 메뉴의 빈 노드 워크플로에서 실행 순서를 직접 연결합니다.

운영체제별 설치 파일과 업데이트 피드는 버전 태그, 명시적인 수동 배포, 또는 `[release]`를 표시한 main 커밋의 검증이 모두 통과한 뒤 게시합니다. 최신 설치 파일은 [GitHub Releases](https://github.com/Furu002/imperium-terminal/releases)에서 받을 수 있습니다.

로컬 웹 서버를 데스크톱 창이나 브라우저에서 사용합니다. 여기서 시작한 작업을 추적하며, 기존 ChatGPT·Claude 앱의 대화나 다른 터미널의 세션을 관찰하지는 않습니다.

## 터미널 화면과 지식 노트

상단 탭에서 조직도·스킬·업무·기억·설정으로 이동합니다. 대화·협업 보드·노드 워크플로·터미널·프로젝트·사용량·업데이트는 도구 메뉴에서 엽니다. `Ctrl/Cmd+K`로 상시 표시되는 명령줄에 포커스합니다. 로컬에 포함된 Pretendard로 결과를 18px 이상에서 읽을 수 있습니다.

업무 지시의 **완료 검사 설정**을 켜면 완료 기준을 에이전트에 전달하고 정상 종료 뒤 답변이 있는지 확인합니다. Codex와 Claude에는 해당 작업이 협업 보드에 게시해야 할 결과의 제목도 지정할 수 있습니다. 검사 근거는 작업 상세에 기록되며, 작업 품질과 사용자 기준의 충족 여부는 답변과 근거를 직접 검토합니다. 연결된 워크플로에서도 시작 에이전트에 완료 검사를 설정할 수 있습니다. 해당 검사가 실패하면 연결된 후속 작업을 중단합니다.

작업을 선택하면 같은 화면의 큰 결과 패널에서 읽습니다. 답변의 **창 보기**는 앱 안에 이동·크기 조절이 가능한 비모달 창을 엽니다. **전체화면**은 앱 화면을 결과로 채우며, 제목줄 두 번 클릭으로 창과 전체화면을 전환합니다. **창 복원**, **패널로**, **닫기**로 돌아갈 수 있고 `Esc`는 전체화면 → 창 → 패널 순서로 복원합니다. 창 밖의 업무 화면도 계속 사용할 수 있습니다. 원문·글자 크기·펼친 정보·읽던 위치는 전환 중 보존되고 실시간 답변도 갱신됩니다. 프로젝트·대화가 바뀌면 소유한 결과창을 닫습니다. 좁은 화면에서는 작업 목록·지시 작성을 접어 결과 공간을 확보합니다.

스킬 화면에서 현재 프로젝트 안의 UTF-8 `SKILL.md` 경로를 등록한 뒤 담당 에이전트를 골라 장착합니다. 원문과 SHA-256 버전을 확인할 수 있으며 GitHub 출처 URL은 참고 정보로만 저장합니다. 원격 저장소를 자동 설치하지 않습니다. 파일은 32 KiB, 에이전트에 전달하는 스킬 지침 합계는 16 KiB까지 지원합니다. 변경된 파일은 조용히 교체하지 않고 해제·재등록을 요구합니다. 장착은 도구 권한을 확대하거나 실제 사용 성공을 의미하지 않으며, 실제 호출·문서 읽기·모델 보고는 실행 기록에서 따로 확인합니다. 등록 삭제는 원본 파일을 지우지 않습니다.

조직도의 목표 입력은 기존 지시 초안과 동기화됩니다. 업무 화면에서 담당자·모델·권한을 확인한 뒤 실행합니다. 목표 자동 분해·검수·최종 통합 엔진은 아직 구현되지 않았습니다.

검정과 차콜 배경에서 호박색으로 명령·표 제목·선택을 강조합니다. 녹색은 연결·완료, 적색은 실패, 청록색은 모델 정보와 링크에 사용합니다. 색상과 정보의 밀도는 [Bloomberg 터미널 화면](https://www.youtube.com/watch?v=BqgqwO11abk)을 참고했습니다.

`HELP`에서 명령어·화면 이름·단축키를 검색할 수 있습니다. `MEMORY`는 프로젝트 지식, `TERM`은 실제 터미널, `FIND 검색어`는 기억 검색입니다. `TASK 지시문`은 담당 에이전트와 실행 설정을 검토할 수 있도록 지시 입력란을 준비합니다. 명령 탐색과 작업 영역은 [Fincept Terminal](https://github.com/Fincept-Corporation/FinceptTerminal/blob/main/docs/ARCHITECTURE.md)과 [Terminal](https://github.com/michaelshimeles/terminal)을 참고했습니다.

프로젝트 기억은 옵시디언의 [그래프](https://obsidian.md/help/plugins/graph)와 [내부 링크](https://obsidian.md/help/links)를 참고한 노트 탐색기·지식 그래프·편집기 구조입니다. `[[노트 제목]]`이나 `[[노트 제목|표시 이름]]`으로 기존 노트를 연결하고 링크와 역링크를 따라 이동할 수 있습니다. 전체 그래프와 선택 노트 주변 그래프를 전환하고 확대·이동합니다. 제목이 중복되거나 대상이 없는 링크는 임의의 노트에 연결하지 않습니다. 노트 원문과 검토·고정·수정 이력은 기존 프로젝트 저장소에 유지됩니다.

이 기능은 저장된 지식과 연결을 검색해 다음 작업의 문맥으로 재사용합니다. 모델 가중치를 학습하는 신경망이나 옵시디언 파일 동기화 기능을 의미하지 않습니다. 처음에는 빈 기억 공간이며 사용자가 저장한 기록만 표시합니다.

v1.7.0은 검정·중성 회색 바탕과 주황·청록·초록 상태색을 사용합니다. 프로젝트 기억 그래프는 GitHub의 [Cytoscape.js](https://github.com/cytoscape/cytoscape.js) 3.35.0, 사용량·성능 차트는 [Chart.js](https://github.com/chartjs/Chart.js) 4.6.1을 로컬로 포함합니다. 확대·이동·노드 선택과 차트 툴팁을 지원하며, 키보드용 노드 목록과 원본 수치표도 제공합니다. 라이브러리 표시에는 인터넷이나 AI 호출이 필요하지 않습니다. 실제 기록이 없는 수치는 빈 상태로 유지합니다. 라이선스와 원본 출처는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.

OUTPUT은 요청과 AI 답변을 나눠 읽는 대화형 결과 화면입니다. 제목·목록·표·코드 블록을 읽기 편하게 표시하고 코드 복사, 원문 보기와 넓게 보기를 제공합니다. 원본 결과와 내보내기는 보존하며, 실행 설정과 처리 로그는 세부 정보에서 확인합니다. 모델이 반환한 HTML이나 외부 이미지는 자동 실행·로드하지 않습니다.

상단의 제공자 로고는 등록한 연결과 현재 프로젝트의 실제 실행 상태를 표시합니다. 실행 중에만 움직이며 대기·로그인 필요·연결 오류·로컬 전용 비활성을 구분합니다. 실행 중에는 **실시간 진행**에서 모델이 공개한 수행 요약, 실제 도구 이벤트, 보고한 진행률·예상 시간을 확인하고 해당 작업의 답변으로 이동합니다. 공개 요약은 실행 기록에도 남습니다. 내부 사고 원문은 수집하지 않으며, 모델이 요약·진행률을 보고하지 않으면 임의로 생성하지 않습니다. 단계 요약은 `[[IMPERIUM_STATUS {"summary":"공개 가능한 수행 단계"}]]`, 수치가 있는 경우 기존 `IMPERIUM_PROGRESS` 형식으로 전달됩니다.

## 데스크톱 실행

등록한 모델은 **AI 계정(F5) → 모델 연결 제거**, 에이전트는 노드 검사기의 **에이전트 제거**에서 정리합니다. **캔버스에서 제거**는 배치한 노드만 빼는 별도 동작입니다. 제거 전에 대상 이름과 보존 범위를 확인하며, 실행·대기·프로세스 종료 대기 중인 항목이나 다른 프로젝트에 할당된 연결은 제거하지 않습니다. 에이전트를 제거해도 대화·작업 결과·기억·CLI 로그인은 유지하고 기존 대화는 읽기 전용으로 남깁니다.
**CHAT → 대화**에서 같은 에이전트에게 후속 질문을 보낼 수 있습니다. Codex·Claude는 앱이 직접 캡처한 공식 CLI 세션으로 재개하고, 실행 중 추가 질문은 같은 대화의 입력 순서대로 대기합니다. **새 대화**를 누를 때만 새 문맥을 선택합니다. 프로젝트·에이전트·제공자·연결·요청 모델·파일 권한이 달라지면 대화를 분리합니다. 다른 제공자는 보관된 이전 완료 응답을 최대 12,000자의 기록 문맥으로 전달하며 화면에서 재개 방식을 구분합니다. 기존 버전의 작업에서 캡처하지 않은 CLI 세션을 임의로 검색하거나 다른 앱의 대화를 가져오지 않습니다. 이전 성공 응답의 네이티브 세션을 확인할 수 없으면 명시적으로 실패하며 새 세션으로 조용히 대체하지 않습니다.

F2의 독립 작업과 기본 워크플로는 새 대화로 실행하며, 기존 대화를 명시적으로 선택한 CHAT의 후속 질문만 이어갑니다.

각 답변과 작업 목록에는 요청 모델을 표시하며, CLI가 실행 모델을 명시적으로 보고하면 별도로 표시합니다. 별칭·기본 설정·사용량을 근거로 실제 모델을 추측하지 않습니다. 화면의 대화 내역과 입력 초안은 프로젝트·대화별로 관리하며, 답변 원문·복사·실행 기록도 그대로 확인할 수 있습니다.

**설정(F8) → 권한·변경 검토**에서 앱 전체를 읽기 전용으로 제한하거나 기존의 작업별 파일 수정 선택을 사용할 수 있습니다. 전역 읽기 전용은 서버에서도 수정 작업을 거절합니다. 실제 터미널은 별도로 켜고 끄며, 끄면 기존 앱 터미널 세션도 닫습니다. 실행·대기 중인 AI 작업이 있으면 권한 정책 변경을 거절합니다. Codex는 CLI 샌드박스를, Claude는 제한된 도구 목록을 사용합니다. Claude의 도구 목록 제한은 OS 파일 격리가 아니며, 터미널은 사용자 OS 권한으로 실행됩니다. 관리자 권한·전체 접근·승인 우회 옵션은 추가하지 않습니다.

**Git 변경 검토**는 현재 프로젝트의 작업 트리·스테이징 diff와 추적하지 않는 파일 이름을 읽기 전용으로 표시합니다. 외부 diff·textconv를 실행하지 않고, 새 파일의 내용은 자동으로 읽지 않습니다. 이 목록은 현재 Git 상태이며 특정 AI 작업만의 변경 내역이나 승인 결과는 아닙니다. Git이 없거나 저장소가 아니면 그 상태를 표시합니다. 검토 창에서 적용·되돌리기·스테이징·커밋을 수행하지 않습니다.

**스킬 사용 현황**은 현재 작업의 실시간 진행 패널에 표시하며 실행 기록에 보존합니다. Claude가 명시적으로 보낸 `Skill` 도구 호출, `Read` 도구의 `SKILL.md` 문서 읽기, 모델의 `IMPERIUM_SKILL` 자기보고를 서로 다른 출처로 표시합니다. 도구 호출 감지는 성공을 보장하지 않고 자기보고는 독립적으로 검증된 실행 증거가 아닙니다. CLI가 공개하지 않은 사용 내역은 확인할 수 없으며, 설치된 스킬을 전부 사용 중으로 표시하지 않습니다. 스킬 이름을 관측하기 위해 도구 권한을 넓히거나 스킬 파일을 새로 실행하지 않습니다.

Windows 내부 검증용 설치 파일은 **`Imperium-Setup-1.7.0-x64.exe`** 형식이며 설치 마법사를 포함합니다.

1. 설치 파일을 실행하고 **다음(Next) → 설치(Install) → 마침(Finish)** 순서로 진행합니다. 설치 폴더를 변경할 수 있으며 현재 Windows 사용자용으로 설치됩니다.
2. 바탕 화면이나 시작 메뉴의 **IMPERIUM** 바로가기로 앱을 엽니다.
3. 제거할 때는 Windows 설정의 앱 목록에서 **IMPERIUM**을 선택합니다.

설치 없이 실행하려면 포터블 파일 `Imperium-1.7.0-win-x64.exe`를 사용하세요. 두 방식 모두 자체 창에서 열리며, 모델 연결에는 아래의 Codex·Claude Code 설치 및 구독 로그인이 필요합니다.

저장소에 접근할 수 있는 개발자는 Actions의 **Build Imperium desktop** 워크플로를 실행하고, 성공한 실행의 **Artifacts**에서 운영체제에 맞는 검증 파일을 받을 수 있습니다. Windows는 `imperium-windows-x64`, macOS는 `imperium-macos-intel-apple-silicon`, Linux는 `imperium-linux-x64`입니다. macOS용 DMG·ZIP은 macOS 러너의 빌드가 성공한 뒤 받을 수 있습니다. Apple Silicon 파일명은 `Imperium-1.7.0-mac-arm64.dmg`·`.zip`, Intel 파일명은 `Imperium-1.7.0-mac-x64.dmg`·`.zip`입니다.

제작자 메타데이터의 이름은 **Sato Junichiro**입니다. 이 이름을 넣는 것만으로 Windows가 게시자를 인증하지는 않습니다. 실제 Authenticode 인증서를 제공해 서명하기 전까지는 코드 서명이 없는 개발용 빌드이며, Windows에 확인되지 않은 게시자로 표시될 수 있습니다. Windows의 보안 안내에서는 출처를 확인한 앱만 개별 실행하세요. macOS에서 차단되면 시스템 설정의 개인정보 보호 및 보안에서 해당 앱에 한해 열기를 허용할 수 있습니다. 운영체제 전체의 보안 설정을 끌 필요는 없습니다.

데스크톱 앱의 기록은 운영체제별 앱 데이터 위치의 `hq-data/`에 저장됩니다. 새 설치의 초기 작업 폴더는 사용자 홈의 `Imperium Projects/Workspace`이며, 새 프로젝트도 사용자 홈의 `Imperium Projects`에 만듭니다. 기존에 저장한 작업 폴더는 유지합니다. **프로젝트(F9)**에서 이름과 색상을 정해 별도의 실제 작업 폴더를 만들고 선택할 수 있습니다.

## Linux 설치

Linux x64 빌드 대상은 Debian·Ubuntu용 `Imperium-1.7.0-linux-amd64.deb`와 직접 실행하는 `Imperium-1.7.0-linux-x86_64.AppImage`입니다. 검증용 패키지를 받은 경우 파일의 폴더에서 필요한 명령을 실행하세요.

Debian·Ubuntu에 설치하려면:

```sh
sudo apt install ./Imperium-1.7.0-linux-amd64.deb
```

설치 후 앱 메뉴의 **IMPERIUM** 항목으로 실행할 수 있습니다. AppImage를 사용하려면:

```sh
chmod +x Imperium-1.7.0-linux-x86_64.AppImage
./Imperium-1.7.0-linux-x86_64.AppImage
```

AppImage는 앱 메뉴나 바탕 화면에 바로가기를 자동으로 만들지 않습니다. Linux에서도 Codex·Claude Code 설치와 구독 계정 로그인이 필요합니다. CI의 Linux 빌드 성공은 패키지 생성과 자동 검사 결과를 의미하며, Linux 데스크톱의 수동 실행 검증을 의미하지 않습니다.

## 소스에서 웹 모드 실행

[Node.js](https://nodejs.org/) 22 이상이 필요합니다. 이번 버전은 실제 터미널·Excel 내보내기 등의 의존성을 사용하므로 먼저 이 폴더에서 패키지를 설치하세요.

```sh
npm ci

```

[http://127.0.0.1:4310](http://127.0.0.1:4310)을 여세요. Windows에서는 `start-headquarters.cmd`를 실행해도 됩니다. 종료는 서버 터미널에서 `Ctrl+C`를 누르세요.

서버를 켠 상태에서 다른 터미널에 아래 명령을 실행하면 키보드로 사용하는 ANSI 터미널 뷰도 열 수 있습니다.

```sh
npm run terminal
```

`HQ_PORT` 환경 변수로 기본 포트 4310을 변경할 수 있습니다.

## 구독 계정 연결

사용할 CLI만 설치하고, 구독 중인 계정으로 로그인하세요. 아래 명령은 별도 도구를 설치하는 명령이며 앱 실행에 필요한 패키지 설치와는 구분됩니다.

```sh
npm install -g @openai/codex
codex login
```

```sh
npm install -g @anthropic-ai/claude-code
claude auth login
```

Codex에서는 ChatGPT 계정을, Claude Code에서는 Claude 구독 계정을 선택하세요. 앱의 연결 화면에서 설치·로그인 상태를 새로고침할 수 있습니다. 한쪽만 준비되어 있다면 지시할 때 준비된 모델을 선택하면 됩니다.

Codex·Claude Code에서 구독 로그인을 선택한 경우 별도 API 키 없이 해당 계정의 이용 조건과 한도를 적용받습니다. [OpenAI 공식 안내](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)와 [Claude 공식 안내](https://support.claude.com/en/articles/11145838-use-claude-code-with-your-pro-max-or-ultra-plan)를 확인하세요. 모델 ID를 지정한 연결은 그 ID를 사용하며, 비워 두면 CLI 기본 설정을 따릅니다. 구독 이름에 맞춰 특정 모델이나 추론 강도를 강제하지 않습니다. 모델 접근 가능 여부, 추가 사용료와 크레딧 조건은 각 서비스가 결정하며 IMPERIUM이 무료 사용이나 비용 절감을 보장하지 않습니다.

**AI 연결(F5)**에서는 Codex, Claude Code, Gemini CLI, GitHub Copilot CLI, Ollama의 다섯 제공자를 등록할 수 있습니다. 각 사용자는 자신의 컴퓨터와 OS 사용자 계정에서 공식 CLI에 로그인합니다. 같은 OS 사용자 아래의 연결은 해당 CLI 로그인을 공유하므로, 표시 이름을 여러 개 등록해도 서로 독립된 인증 계정이 만들어지지는 않습니다. 중앙 서버에서 여러 사람의 구독 계정을 공유하는 서비스가 아닙니다.

모델 목록의 **계정에서 확인**, **CLI 별칭**, **로컬 모델**, **직접 입력** 표시는 서로 다른 출처를 뜻합니다. 별칭이나 직접 입력한 ID를 계정에서 확인된 이용 권한으로 해석하지 마세요. 목록을 자동으로 확인할 수 없으면 공식 CLI에서 사용 가능한 모델을 확인한 뒤 ID를 입력합니다. Gemini는 CLI 설치 감지만으로 로그인 여부가 확정되지 않을 수 있으므로 공식 CLI에서 Google 계정 로그인을 확인하세요. Ollama는 이 컴퓨터에 설치된 로컬 모델을 사용합니다.

## 모델·추론·속도 선택

v1.7.0에서는 역할·에이전트 설정에 실행 모델, 추론 강도와 응답 속도의 기본값을 저장하고, **작업(F2)**의 **이번 작업 모델 설정**에서 해당 작업만 다르게 지정할 수 있습니다. **계정 모델 불러오기**는 Codex·Claude Code가 반환한 모델과 지원 옵션을 조회합니다. Claude의 별칭과 실제 모델 ID도 함께 식별합니다. 직접 입력한 모델 ID의 이용 권한과 모든 옵션의 지원 여부를 보장하지는 않습니다.

| 설정 | 동작 |
| --- | --- |
| 모델·추론 기본값 | 별도 모델 ID나 추론 단계를 강제하지 않고 CLI·모델 설정을 따릅니다. |
| 속도 기본값 | 기존 CLI 속도 설정을 상속하므로 Fast가 켜져 있을 수도 있습니다. |
| Standard | Codex·Claude에서 Fast를 명시적으로 끄고 표준 속도를 요청합니다. |
| Fast | 지원되는 모델과 계정에 빠른 처리를 요청합니다. 추가 사용량이나 요금이 발생할 수 있습니다. |

Codex의 추론 옵션은 선택 모델이 보고한 목록에 따라 제한합니다. `max`·`ultra`도 해당 모델이 지원할 때만 선택합니다. Claude의 `low`·`medium`·`high`·`xhigh`·`max`도 모델별 지원 목록을 따릅니다. Copilot의 추론 단계는 모델·CLI 지원에 따라 달라지며 속도는 기본값만 제공합니다. Gemini·Ollama의 추론·속도는 이 버전에서 기본값만 제공합니다. 미지원 옵션은 기본값으로 되돌립니다.

**Claude Fast는 구독의 기본 이용 한도와 별도인 사용 크레딧을 소비합니다. 기본 한도가 남아 있어도 별도 크레딧이 필요합니다.** 계정·조직에서 허용하고 추가 사용 조건을 확인한 경우에 선택하세요. [Claude Fast 공식 안내](https://code.claude.com/docs/en/fast-mode)와 [Codex 설정 안내](https://learn.chatgpt.com/docs/config-file/config-reference)를 참고하세요.

작업 상세의 **요청 실행 설정**은 저장하고 CLI에 전달한 요청값입니다. 사업자가 실제 적용한 모델·추론·속도는 계정 권한, 조직 정책, 모델 지원과 서비스의 대체 처리에 따라 달라질 수 있습니다. 이 표시는 Fast 적용이나 특정 성능을 확인한 측정값이 아닙니다. 설정은 작업 실행에만 전달하며 공식 CLI의 전역 설정 파일을 수정하지 않습니다.

## 계정별 잔여 한도

화면 상단의 **계정별 잔여 한도**에서 사용·잔여 비율, 리셋 예정 시각, 출처와 확인 시각을 볼 수 있습니다. **상세**로 펼치고 **새로 조회**로 갱신하세요. 값은 같은 OS 사용자가 로그인한 **제공자 계정 전체의 공유 한도**입니다. 프로젝트나 모델 이름표마다 별도 잔액이 생기지는 않습니다.

- **Codex**: 공식 계정 인터페이스가 보고한 시간 구간별 이용 한도와, 제공되는 경우 크레딧 잔액을 표시합니다.
- **Claude Code**: 공식 CLI의 사용량 조회로 5시간·주간·모델 범위 한도를 표시하고, 실행 중 보고된 한도 이벤트로 해당 구간을 보완합니다. 추가 사용 금액은 통화와 단위가 확인된 경우에만 표시합니다. 이 조회 인터페이스는 실험적이어서 CLI 버전에 따라 사용할 수 없을 수 있습니다.
- **Copilot**: 공식 CLI가 공개한 계정 한도·요청 수·잔여 비율을 표시합니다. 비율 없이 사용 수와 한도만 제공되면 그 값으로 비율을 계산합니다.
- **Gemini**: 이 버전에서는 잔여 한도의 자동 조회를 제공하지 않으며 공식 사용량 안내로 연결합니다. **Ollama** 로컬 모델에는 클라우드 구독 잔여 한도를 적용하지 않습니다.

잔여 비율은 남은 메시지 수나 금액으로 환산하지 않습니다. 제공되지 않은 잔액·리셋 시각은 알 수 없음으로 남기며, 작업 토큰에서 계정 잔량을 추정하지 않습니다. 기본 캐시는 60초이고 수동 새로 조회도 최소 10초 간격으로 제한합니다. 2분 이상 지났거나 리셋 예정 시각이 지난 값은 이전 조회값으로 구분하므로 다시 확인하세요.

모델 목록과 한도 조회는 **모델 추론이나 사용자 프롬프트 전송 없이** 공식 CLI의 메타데이터 인터페이스만 사용합니다. 계정 조회를 위한 클라우드 통신은 필요합니다. 로컬 전용 모드에서는 클라우드 한도 조회를 중단하고 진행 중인 조회를 취소하며 외부 사용량 링크를 숨깁니다.

## 사용 흐름

새 작업 공간의 첫 화면은 **빈 캔버스(F1)**입니다. **노드 라이브러리**에서 본인, AI와 역할·기억을 직접 추가합니다. 본인 이름은 ‘나’나 원하는 이름으로, 직함도 자유롭게 정할 수 있습니다. 각 AI의 명찰로 연결과 역할을 구분합니다. 회사 형태를 원할 때만 **조직 템플릿**을 명시적으로 적용하세요. 기존에 저장한 프로젝트는 저장된 캔버스를 복원합니다.

1. **프로젝트(F9)**에서 작업할 프로젝트를 선택하거나 이름·색상·상위 폴더를 정해 새 폴더를 만듭니다. 새 프로젝트는 빈 구성에서 시작합니다.
2. **AI 연결(F5)**에서 사용할 CLI의 설치·로그인을 확인하고, 캔버스에 필요한 AI와 역할을 추가합니다. 역할의 **업무 지시**는 해당 역할을 선택한 작업 화면으로 이동할 뿐 모델을 호출하지 않습니다. **F2**로 작업 화면을 바로 열 수도 있습니다.
3. 지시를 입력하고 준비된 제공자·연결을 선택합니다. 필요하면 **이번 작업 모델 설정**에서 역할의 기본 모델·추론 강도·속도를 재정의합니다.
4. 읽기 전용 또는 파일 수정 권한과 우선순위를 정한 뒤 **지시 보내기**로 실제 작업을 시작합니다.
5. 실시간 로그·결과·상태를 확인하고 필요하면 작업을 취소합니다. 기록은 JSON 또는 실제 Excel 통합 문서(`.xlsx`)로 내보낼 수 있습니다.

역할·부서 노드는 작업을 맡기는 정의이며, 항상 실행 중인 독립 모델 프로세스는 아닙니다. 프로젝트마다 역할·에이전트 정의, 캔버스와 기억을 분리합니다. CLI 로그인과 등록한 모델 연결은 같은 OS 사용자에서 프로젝트 간 공유됩니다. 프로젝트를 바꾸어도 별도의 구독 계정이 생기지 않습니다. 프로젝트를 전환하려면 실행·대기 작업을 먼저 완료하거나 취소하세요.

캔버스의 실행 상태와 완료 여부는 실제 작업 상태를 따릅니다. AI가 공개한 단계·진행률·남은 시간은 **모델 추정**으로 구분하며 정확한 완성도나 종료 시각을 보장하지 않습니다. 과거 기록으로 계산한 시간도 **기록 기반 추정**입니다. 실제 완료가 확인된 작업만 100%로 표시합니다.

작업은 모델별 한 번에 1개, 전체 최대 2개까지 실행합니다. 같은 부서의 작업도 순서대로 실행하며, 파일 수정 작업은 충돌을 줄이기 위해 다른 작업과 겹치지 않게 실행합니다. 전체 동시 실행 수는 1 또는 2로 설정할 수 있습니다.

**DEMO**는 모델을 호출하지 않는 예시입니다. 화면의 데모 실행·삭제 기능으로 스트리밍과 상태 변화를 확인할 수 있습니다. 실제 모델은 사용자가 실제 작업을 지시한 경우에 호출됩니다.

## 노드·기억·워크플로

- 노드를 끌어 위치를 바꾸고, 빈 공간을 끌거나 휠로 이동합니다. `Ctrl+휠`로 확대·축소하고 **화면 맞춤**·**자동 배치**를 사용할 수 있습니다. 위치와 연결은 프로젝트별로 저장됩니다.
- **기억 추가**에서 기존 기억을 선택하거나 새 기억을 만듭니다. 기억 노드의 출력 포트를 부서 입력 포트에 연결하면 해당 기억을 작업 문맥으로 전달합니다. 검사기에서 내용·고정 여부·수정 번호를 확인하고 편집합니다. **캔버스에서 제거**는 기억 자체를 삭제하지 않습니다.
- 역할의 출력 포트를 다른 역할의 입력 포트에 연결하면 업무 전달 흐름이 됩니다. 연결은 순환할 수 없습니다. 선을 선택해 삭제할 수 있습니다.
- 연결만으로 작업은 실행되지 않습니다. 부서를 선택해 지시를 작성하거나 검사기의 **연결된 흐름 실행**에서 명시적으로 워크플로를 시작하세요. 기본 권한은 읽기 전용입니다.

기억은 로컬 파일에 저장되는 프로젝트별 노트·결정·제약·작업 결과입니다. **지식(F11)**에서 실제 작업 결과와 고정한 노트로 구성된 지식 그래프를 확인합니다. 검색과 자동 관계는 **프로젝트 범위의 키워드 RAG**이며 모델 가중치를 학습시키지 않습니다. 자동 수집한 작업 결과는 `unverified` 자료입니다. 사람이 원문을 검토·수정하고 중요한 노트를 고정하세요. 에이전트는 고정된 내용과 사용자 작성 내용을 덮어쓸 수 없습니다. 고정 자체가 내용의 사실성을 자동 검증하지는 않습니다.

Codex·Claude 작업에는 실행 중에도 기억을 추가 조회할 수 있는 읽기 전용 MCP 도구 `memory_search`, `memory_get`, `memory_list`가 연결됩니다. 접근 범위는 해당 작업과 프로젝트로 제한됩니다. 모델이 필요할 때 조회하는 기능이며, 항상 모든 기억을 읽거나 백그라운드에서 스스로 학습하는 기능은 아닙니다.

## 프로젝트와 로컬 전용 모드

**프로젝트(F9)**는 실제 새 폴더를 만들며, 기본 상위 폴더는 현재 작업 폴더 옆의 `Imperium Projects`입니다. 다른 기존 상위 폴더를 지정할 수도 있습니다. 기존 폴더를 덮어쓰거나 옮기지 않습니다. 프로젝트 이름·색상은 편집할 수 있고, 역할 정의·노드 배치·기억 검색은 선택한 프로젝트에 한정됩니다.

설정의 **로컬 전용**(`settings.localOnly`)을 켜면 앱은 이 컴퓨터의 Ollama에 설치된 로컬 모델만 실행합니다. 클라우드 작업과 클라우드 모델 목록 조회는 HTTP 403으로 거절하며 데스크톱 자동 업데이트의 확인·다운로드도 중단합니다. 대기·실행 작업이 있다면 먼저 마친 뒤 모드를 바꾸세요. 이 설정은 앱의 모델·업데이트 경로에 적용되며 **실제 터미널에서 직접 실행한 외부 명령이나 운영체제의 네트워크 연결까지 차단하지는 않습니다**.

## 사용량과 성능

**분석(F10)**은 현재 프로젝트의 보관된 실제 작업을 기준으로 토큰 추이·작업별 그래프, 첫 출력 지연과 전체 실행 시간의 p50·p95, 완료·실패 작업의 성공률을 표시합니다. DEMO는 제외하며, CLI가 사용량을 보고하지 않은 작업은 미보고로 표시합니다. 누락값을 0이나 추정 청구액으로 바꾸지 않습니다.

이전·최근 비교는 같은 제공자·모델 ID·역할·권한에서 사용량이 보고된 완료 작업이 **최소 6개**일 때 이전 3개 이상과 최근 같은 수를 비교합니다. 관측된 토큰 변화이며 기억 기능의 인과적 효과나 비용 절감 증거는 아닙니다. 모델 ID를 알 수 없는 작업은 비교에서 제외합니다. 계정별 잔여 한도는 위의 공식 조회값으로 별도 표시하며, 작업 토큰을 잔여 한도나 청구 절감액으로 환산하지 않습니다.

기억의 **초기 문맥 문자 선별률**은 저장된 기억 중 처음 전달한 문자 분량을 비교한 값입니다. 이후 MCP 조회와 CLI 자체 문맥·토큰화를 모두 반영한 청구 토큰 측정값이 아니므로 실제 요금 절감률로 해석하지 마세요. 설계 근거와 계측의 범위는 [구조와 검증 원칙](docs/architecture.md)에 설명합니다.

## Excel 기록 내보내기

`.xlsx`에는 **요약·작업·작업 결과·부서·이벤트·기억·모델 연결**의 일곱 시트가 들어갑니다. 언어 설정에 따라 시트명·헤더가 한국어·English·日本語로 표시됩니다. 작업 지시와 실제 결과를 포함하며, 긴 결과는 32,000 UTF-16자 이하의 번호 있는 조각으로 나눠 원문을 보존합니다. 사용량은 CLI가 보고한 값만 기록하고, 인증 토큰·API 키·터미널 출력·서버 내부 상태는 제외합니다. 사용자 문자열은 수식이 아닌 문자 셀로 저장합니다.

## 언어와 권한

화면의 언어 선택에서 한국어·English·日本語를 전환할 수 있으며 선택은 앱 설정과 해당 브라우저에 저장됩니다. 이 설정은 화면의 설명과 표시 문구에 적용됩니다. 모델 응답은 지시 내용과 서버의 기본 한국어 안내를 따르므로 다른 언어의 결과를 원하면 지시에 명시하세요. 부서에 직접 입력한 이름·역할도 자동 번역되지 않습니다.

Pretendard·Pretendard JP·JetBrains Mono 글꼴은 `public/fonts/`에 포함되어 외부 글꼴 CDN 없이 사용합니다. SIL Open Font License 1.1의 라이선스와 출처는 [서드파티 고지](THIRD_PARTY_NOTICES.md)에 정리되어 있습니다.

## 업데이트와 배포 상태

소스와 업데이트 배포 채널은 [Furu002/imperium-terminal](https://github.com/Furu002/imperium-terminal)입니다. 저장소 공개 전환에는 소유자 재인증이 필요할 수 있습니다. 버전과 같은 `v1.7.0` 형태의 태그를 게시하면 Windows·macOS·Linux 빌드가 모두 성공한 뒤 설치 파일·SHA256SUMS·업데이트 메타데이터를 릴리스에 게시하도록 설정했습니다. **업데이트(F7)**는 시작 시와 5분 간격으로 확인하며 다운로드와 설치는 직접 선택합니다. 로컬 전용 모드에서는 업데이트 통신도 중단합니다.

Windows 설치본은 NSIS 업데이트 경로를 사용하고, Linux AppImage는 AppImage 업데이트 경로를 사용합니다. Linux DEB는 새 패키지를 받아 수동으로 설치합니다. macOS는 서명 인증서가 없는 현재 구성에서 수동 업데이트가 필요할 수 있습니다. 파일 해시 검증은 코드 서명을 대신하지 않으며 **Sato Junichiro** 제작자 메타데이터도 인증서 서명이 아닙니다. 방화벽이나 OS 보안 설정 전체를 끄는 절차는 제공하지 않습니다.

## 에이전트 협업과 기억 정리

**TEAM / 협업 보드**에서 현재 프로젝트의 실제 작업, 공유 산출물, 게시·참조 이력을 확인합니다. 에이전트는 실행 중 제공되는 프로젝트 한정 MCP 도구로 동료의 공개 진행·결과를 읽고 중간 산출물을 게시할 수 있습니다. 게시물은 출처가 붙은 미검증 자료이며 고정된 사용자 메모를 덮어쓰지 않습니다. 작업 종료·취소 뒤에는 해당 작업의 접근 토큰을 사용할 수 없습니다. 결과가 필요한 단계에서만 읽도록 안내하며 반복 호출이나 자동 추가 에이전트 생성은 하지 않습니다.

노드 연결 뒤 **연결 에이전트 실행**에서 시작점·도달 에이전트·실행 수·권한과 차단 사유를 확인하고 실행합니다. 순차 연결은 실제 완료 결과를 다음 작업에 전달합니다. n8n의 수동 실행·상태·이력 확인 방식을 참고해 구현했으며 n8n 코드는 포함하지 않습니다. 동료 도구의 호출 횟수나 요금 절약을 보장하지 않습니다.

**MEMORY**의 불필요한 노트는 보관함으로 옮기고 복원할 수 있습니다. 보관된 항목은 활성 그래프와 검색 문맥에서 제외됩니다. 수동 연결만 선택해 해제할 수 있고, 문서 링크로 만든 연결은 원문의 `[[링크]]`를 수정합니다. **자연 배열**은 MIT 라이브러리 fCoSE를 사용해 약 600ms 동안 정렬하며 움직임 감소 설정을 따릅니다. 일반 실시간 갱신은 배치를 다시 섞지 않습니다.

답변은 기본 18px, 크게 읽기 창은 20px부터 표시하며 A−/A+로 14~28px를 선택합니다. 모델 활동 표시는 실제 제공자 로고를 로컬 파일로 사용합니다.
